# MYOS-Editor-Test
Building an editable website where users can update text and images without changing the source code. Have any ideas or suggestions? Please open a GitHub Issue!

## Project Goal

I want to build a completely free system that allows website owners to edit their live websites without changing any source code.

For example, someone who owns a restaurant website should be able to:

- Upload or replace images directly from their phone.
- Edit text, headings, and descriptions.
- Update contact information, prices, and other website content.
- Save their changes and see them reflected on their live website.

The system should work with websites hosted on GitHub Pages without requiring website owners to know how to code or manually edit files on GitHub.

## My Goal

Make website editing free and accessible to everyone, so anyone can manage their own website without paying for a website editor.

I'm currently exploring possible solutions and welcome ideas, technical suggestions, and contributions from anyone who can help.
